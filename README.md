# EVENT HUB — Phase 0 foundation

Not yet an application. These files are the approved-pending foundation for Milestone 0.

- `prisma/schema.prisma` — database schema proposal (19 models, Prisma 7, PostgreSQL). Validated; not migrated.
- `prisma.config.ts` — Prisma 7 config (reads DATABASE_URL).
- `design-system/tokens.css` — colour, type, space, radius, elevation and motion tokens.
- `design-system/theme.css` — Tailwind CSS v4 bridge (import after tokens.css).
- `design-system/style-guide.html` — self-contained visual reference; open in a browser.
- `.env.example` — all 26 environment variables, grouped by the milestone that needs them.

See the "EVENT HUB — Technical Foundation (Phase 0)" doc for architecture, milestones and the decisions awaiting approval.
